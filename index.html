Integração pessoal com Google Drive

Esta página descreve um cliente OAuth pessoal usado para autorizar o rclone a acessar uma conta Google Drive com o consentimento do titular.

O rclone é uma ferramenta de linha de comando executada localmente, utilizada para listar, copiar, comparar e sincronizar arquivos e pastas escolhidos pelo próprio usuário. O acesso ao Google Drive ocorre pela API oficial do Google, conforme as permissões OAuth concedidas.

O cliente OAuth foi configurado para uso pessoal, sem oferta pública de serviços de sincronização, contas de terceiros ou infraestrutura própria de armazenamento.
